# Capturas de proyectos

Las tarjetas de Ciencia Política y Prácticas UNT usan ilustraciones SVG de ejemplo mientras se agregan capturas reales.

1. Guarda las capturas en esta carpeta, por ejemplo `ciencia-politica-unt.webp` y `practicas-unt.webp`.
2. En los archivos correspondientes de `content/es/projects/` y `content/en/projects/`, cambia `image` a `/images/projects/ciencia-politica-unt.webp` o `/images/projects/practicas-unt.webp`.
3. Actualiza `imageAlt` con una descripción de la captura y establece `imagePlaceholder: false` para ocultar el aviso de imagen de ejemplo.

Las tarjetas reservan un espacio de proporción 3:2 (por ejemplo, 960 × 640 píxeles). Las imágenes con otra proporción se recortan para llenar ese espacio.
